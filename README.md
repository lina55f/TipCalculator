# Tip Calculator

A simple Java command-line tool that calculates the tip on a restaurant bill.
Built for SWE 442 (Software Configuration Management) to practice Git and GitHub:
branching, merging, conflict resolution, and release tagging.

## Features (v1.0)
- Takes a bill amount from the user
- Calculates a fixed 15% tip
- Prints the tip and the total

## Planned features (feature branches)
- Split the bill among people
- Custom tip percentage
- Rounding option

## Requirements
- Java JDK 8 or later

## How to run
```bash
javac TipCalculator.java
java TipCalculator
```

## Example
```
=== Tip Calculator v1.0 ===
Enter the bill amount: 200
Tip (15%): 30.00
Total:      230.00
```
